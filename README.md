# Passwort-Generator (PWA)

Dateien auf einen HTTPS-Webspace hochladen (z. B. Netlify Drop, GitHub Pages, Cloudflare Pages),
auf dem iPad in Safari öffnen -> Teilen -> "Zum Home-Bildschirm". Danach läuft die App offline.
Hinweis: Über file:// funktioniert der Service Worker nicht, HTTPS ist Pflicht.
Änderungen an den Dateien: in sw.js die Zahl in CACHE ('passwort-generator-v2' ...) erhöhen.
